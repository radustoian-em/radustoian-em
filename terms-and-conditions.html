1. Overview & Testing Purpose

This is a personal website of Radu Stoian used exclusively for testing, research, and experimental demonstration of agentic AI discovery, Model Context Protocol (MCP), and conversational retrieval protocols.

These Terms and Conditions apply to all human visitors, automated agents, developer integrations, and third-party AI platforms — including ChatGPT public plugins, OpenAI Custom GPT Actions, and Claude desktop tools — that interact with this site or its programmatic endpoints.

By querying or connecting to any endpoint on this site, you acknowledge that you are interacting with a personal experimental testing service operated by Radu Stoian.

2. Covered Endpoints

These Terms apply to all public and agent-facing interfaces provided on this site, specifically:

  • Model Context Protocol (MCP) Server (/mcp): Programmatic JSON-RPC 2.0 endpoint over HTTP POST and Server-Sent Events (SSE) used by AI agents and ChatGPT actions for profile information and tool calls.
  • Conversational Ask Endpoint (/ask): Natural-language retrieval endpoint (/ask, /who, /who.json, /sites) for conversational query processing.
  • Interactive Website Chatbot: The conversational AI widget embedded on radustoian.com that communicates with the /ask endpoint.
  • Public REST API (/api): HTTP REST endpoints (/api and /api/v1/*) returning structured profile data and machine-readable manifests.

All endpoints run on serverless Cloudflare Workers infrastructure and adhere to the unified data handling, observability, and third-party AI processing rules described below.

3. Privacy and Data Handling

When you use the Radu Stoian Profile services — including the Model Context Protocol (MCP) service, the NLWeb conversational Ask endpoint, the interactive website Chatbot widget, and the public REST API — the service records the text of your query as an observability metric for its Cloudflare Worker, along with the requesting agent type and the request’s city and country.

The service does not intentionally collect other user-provided personal information through this observability metric across any of its endpoints. However, query text may itself contain personal information if you choose to include it, so please avoid submitting sensitive or confidential information.

The service is hosted on Cloudflare infrastructure. The handling, access, retention and deletion of observability data are subject to the applicable service configuration and provider terms.

4. Query Data and Observability

When you use the Radu Stoian Profile services — including the MCP endpoint, the conversational Ask service, the website Chatbot widget, and the REST API — the service records the text of your query as an observability metric, together with the requesting agent type and the request’s city and country.

This information is used to monitor and troubleshoot the service. Please do not include passwords, confidential information or sensitive personal information in your queries.

Hosting and retention: The service uses Cloudflare Workers. Observability data is retained according to the applicable Cloudflare logging configuration: the default retention period is seven days, while datasets using the legacy Log Explorer system may be retained for 30 days.

The service does not intentionally collect other user-provided personal information through these observability metrics. Query text may nevertheless contain personal information if you choose to include it.

Cloudflare processes and stores observability data to provide its hosting and logging services. Any additional recipients or processing should be disclosed if applicable.

5. Third-Party AI Processing

To answer questions, the Radu Stoian Profile services — including the MCP service, the conversational Ask endpoint, the website Chatbot widget, and the API — may use the Google Gemini API to classify query intent, apply safety checks, detect language, generate between one and three search queries for internal knowledge-base retrieval, and refine or synthesise a natural-language answer when that feature is enabled.

When Gemini processing is unavailable because the API key is not configured, quota is exhausted, or a request fails or times out, the service falls back to internal search and retrieval within the Cloudflare Worker.

When Gemini is used, relevant query content is sent to Google for processing. Google's handling of that content is governed by the applicable Gemini API terms and privacy commitments. Users should not submit sensitive or confidential information.

The service also records the original query text, requesting agent type, and request city and country as Cloudflare Worker observability metrics. The default retention period for the relevant observability dataset is seven days; legacy Log Explorer datasets may have 30-day retention, depending on configuration.

6. Acceptable Use and Plugin Guidelines

Users and AI plugins connecting to these testing endpoints agree to use them fairly and responsibly:

  • No Confidential or Sensitive Data: Do not submit passwords, API keys, private credentials, or sensitive personal data in any queries.
  • No Abusive or Malicious Requests: Do not transmit prompt injections, automated denial-of-service floods, or illegal materials.
  • Rate Limits: Respect operational limits. The on-site chatbot maintains a 5-question limit per 24-hour session window to manage API costs in this testing environment. Programmatic requests should handle HTTP 429 rate limits gracefully.
  • Accurate Agent Attribution: Third-party plugins and AI assistants should provide an informative User-Agent or client header and accurately present answers as retrieved from Radu Stoian's personal site.
